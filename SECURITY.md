# Security

Lesson Builder turns sources you review into lessons and exercises. Source text and saved lessons stay on your device unless you export or share them. Local files are plaintext protected by account permissions. Treat both as local data and use made-up source text in bug reports. SHA-256 can identify content when compared with a trusted reference, but it does not encrypt text or show whether a source is accurate.

Use your Mac’s disk encryption to protect saved files. The native app has an ad-hoc code signature. This lets the installer check whether its files changed. It does not prove who made the app. The build is not notarized. Saved files follow account permissions.

Report security issues through [GitHub private vulnerability reporting](https://github.com/gmperkinsmba/lesson-builder/security/advisories/new).
